H.E. BENNETT SECURITIES, INC. — BASIC HTML WEBSITE

Files:
- index.html          About / company overview
- services.html       Services
- officers.html       Company Officers & Directors + Traders & Salesmen
- announcements.html  Announcements
- contact.html        Contact Us
- style.css           All visual styling
- script.js            Small mobile menu script
- images/              Portraits and hero illustration

How to edit:
1. Open the .html files in a simple text editor such as Notepad, TextEdit, VS Code, or similar.
2. Find the text you want to change and replace it.
3. Save the file and open it in a web browser.
4. Keep style.css in the same folder as the HTML files.
5. To replace a portrait, put the new image in images/ and change the image filename in officers.html.

Important:
- The PSE price shown in the header is SAMPLE DISPLAY DATA for the mockup. Replace it with an approved/live market-data source before publishing.
- Announcement entries are sample placeholders and should be replaced with official company disclosures.
- Social-media links and VIEW buttons are placeholders until the official destinations are known.
- This version intentionally avoids frameworks, databases, logins, and complicated code so that it remains easy to edit.
